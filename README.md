**Electric Vehicle Population Dataset Analysis **
This project performs Exploratory Data Analysis (EDA) and Data Visualization on the Electric Vehicle Population Dataset. 

**Objectives **
- Data Understanding
- Data Cleaning 
- Data Transformation 
- Exploratory Data Analysis 
- Outlier Detection 
- Visualization of EV Adoption Trends 

**Tools Used **
- Python 
- Pandas 
- NumPy 
- Matplotlib 
- Seaborn  

**Dataset **
- Electric Vehicle Population Dataset from Kaggle.
